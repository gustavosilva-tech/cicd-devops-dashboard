# CI/CD DevOps Dashboard

Projeto de demonstração de pipeline CI/CD com GitHub Actions, testes automáticos e deploy contínuo.

![CI/CD Status](https://github.com/gustavosilva-tech/cicd-devops-dashboard)

🔗 **App online:** https://cicd-devops-dashboard.onrender.com

## Tecnologias

- Node.js + Express
- GitHub Actions (CI/CD)
- Render (deploy automático)

## Como funciona

Sempre que há um push para a branch `main`, o GitHub Actions instala as dependências, corre os testes automáticos, e o Render publica a nova versão automaticamente.

## Como executar localmente

\`\`\`
npm install
npm start
\`\`\`

Depois abre `https://cicd-devops-dashboard.onrender.com` no browser.
